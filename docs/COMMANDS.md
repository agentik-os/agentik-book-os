# Commands

Every command also works in plain language — the bot infers the mode, announces it in one line, and executes. You can talk to it by **voice** (it transcribes) and send it **book files** (PDF/EPUB/text).

## Getting started
| Command | What it does |
|---|---|
| `/start` | What the bot can do |
| `/setup` | Short interview that calibrates the bot on **how you learn** (style, attention, memory sensibilities, domains, language). Writes a profile it reloads every session. Do this first. |
| `/language [code]` | Set the reply language. Default **English**. `/language fr`, `/language español`, `/language auto` (follow the language you write in). |
| `/voice [on\|off\|engine]` | Also reply as a spoken note via the local open-source TTS gateway. Text always lands first. Default off. |

## Books
| Command | What it does |
|---|---|
| `/book [title]` | Full X-ray: the book's DNA, the 20% that carries 80%, chapter map, mental models, critique, application to you, one sentence to remember. |
| `/espresso [title]` | The book in 90 seconds. |
| `/chapter [title\|N]` | A book **chapter by chapter, in full detail** (every field per chapter), or one chapter deep. Delivered as a file with a chat preview. |
| `/best [topic]` | The **50 best books worldwide** (all languages) on a topic + the **50 best actionable tips**, each with how to apply it. |
| `/bestsellers [niche]` | The **top 100 best-sellers** in a niche (by commercial success — distinct from `/best`, which ranks by idea quality). |
| `/readingpath [goal]` | A short, ordered reading path for a specific goal. |

## Ideas & comparison
| Command | What it does |
|---|---|
| `/idea [topic]` | An atlas of an idea across many books and disciplines. |
| `/compare [A] vs [B]` | Put books or authors in intellectual combat: agreements, conflicts, who wins in which situation, a synthesis. |
| `/gem` | One underrated idea from an underrated book, relevant to your context. |

## Think & decide
| Command | What it does |
|---|---|
| `/challenge [idea]` | 10-round sparring on your idea/plan: steelman → assumption map → red team → pre-mortem → the cheapest test → verdict. |
| `/decision [X]` | Decision lab (reversibility, matrix, biases, guardrails). |
| `/council [topic]` | A council of 3–5 perspectives: disagreements, risks, the most robust decision. You can name the perspectives. |
| `/apply [idea → context]` | Translate an idea into your business: a ≤7-day experiment and a concrete deliverable. |

## Learn & remember
| Command | What it does |
|---|---|
| `/teach [concept]` | Feynman mode: child / operator / expert, then it hunts the gap in your understanding. |
| `/memory [concept]` | Forge durable memory (core phrase, image, story, analogy, memory palace, spaced review). |
| `/drill` or `/quiz` | Playful active recall (60-second recall, teach-back, scenario, true/false-with-a-twist, blind rebuild). |
| `/cards [n]` | Flashcards (Anki format on request). |
| `/map [concept]` | Turn a concept into a clean diagram (a crisp image + a full-screen HTML file). |
| `/review` | Spaced repetition — it resurfaces what's due, weak spots first. |
| `/focus [idea]` | A 5-minute micro-session: idea → example → challenge → application → recall. |
| `/audio [topic]` | Listen mode: short sequences, one question at a time, answer out loud. |
| `/masterclass [topic]` | The most complete analysis, hierarchized. |

## Personal memory (on disk)
| Command | What it does |
